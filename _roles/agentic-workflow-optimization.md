## What does an AI Agent Workflow Engineer do?

AI Agent Workflow Engineers design multi-step workflows where LLM agents plan, call tools and hand off to humans, then tune them for reliability, cost and speed.

## A typical week

- Reviewing traces of failed agent runs and tagging root causes
- Adding or refining tools the agent can call
- Running evaluation suites before each prompt or model change
- Agreeing escalation rules with operations teams

## How to show this role on your resume

Lead with measured outcomes per workflow (cost per run, success rate, time saved) and name the orchestration stack. Recruiters filter for concrete frameworks and evaluation experience.
