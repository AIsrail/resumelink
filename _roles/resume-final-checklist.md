## What is this guide about?

A last-step checklist to run before you send any resume: accuracy, ATS readability, keywords, formatting and proof of impact.

## Steps to follow

- Match 10-15 keywords from the job description
- Check contact details, links and dates
- Run an ATS score check
- Export to PDF and review on mobile

## How it shows up on your resume

Run this checklist for each application; a tailored, error-free resume beats a perfect generic one.
